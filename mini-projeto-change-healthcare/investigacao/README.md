# Investigação — Change Healthcare

Este documento apresenta a análise do incidente de cibersegurança sofrido pela Change Healthcare em 2024.

A investigação aborda o contexto do incidente, os conceitos de cibersegurança relacionados, os impactos para a organização e os profissionais envolvidos na resposta ao incidente.
